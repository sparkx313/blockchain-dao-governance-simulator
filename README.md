# 🏛️ DAO Governance Simulator

Simulate and analyze different DAO governance mechanisms.

## Mechanisms
- **Token-Weighted Voting** – 1 token = 1 vote
- **Quadratic Voting** – √tokens = votes (plutocracy resistant)
- **Conviction Voting** – preference accumulates over time
- **Holographic Consensus** – prediction market + voting

## Analysis
- Voter turnout simulation
- Whale dominance analysis
- Sybil attack resistance metrics
- Governance attack cost estimation
